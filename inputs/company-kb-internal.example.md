# MAGPPIE: team-only knowledge (example)

Copy this file to `company-kb-internal.md` and fill it in. That file is never committed.

Everything in it is loaded as team-only knowledge: MAGI may tell it to the team and says it is internal.
The agents that write blogs, creatives and scripts never see it.

Use the same shape as `company-kb.md`: a `#` title for each area, `##` for each topic, short lines under it.

# Company (team only)

## Plans and targets
- ...

## People and hiring
- ...

# Items to verify before anything is published
- ...
