# MAI Output Formats

These are my suggested formats. Edit anything, or replace a section with your own format.

## Blog
- Length: [1,200–1,500 words]
- Language: [English]
- Structure: SEO title (under 60 characters), meta description (under 155), hook intro, 4–6 H2 sections, FAQ (3–5 questions), conclusion with call to action
- Must include: 1 focus keyword + 3–5 related keywords, internal link to our website, sources for any facts

## Creative idea (sent to the creative dashboard)
- Title
- Platform + size: [Instagram post 1080×1350 / story 1080×1920 / LinkedIn 1200×1200]
- Objective: [awareness / engagement / leads]
- Headline (max 8 words)
- Supporting line (max 20 words)
- Visual description (what the image shows)
- Style and colours
- Call to action
- Caption + hashtags
- Inspired by: source link
- Why it fits Magppie: 1 line from the KB

## Video / reel script idea (sent to the video agent)
- Title
- Platform + length: [Instagram reel / YouTube Short, 30–45 seconds, 9:16]
- Hook (first 3 seconds, on-screen text + voiceover)
- Scenes: for each scene — duration, visual, on-screen text, voiceover
- Ending + call to action
- Music mood
- Higgsfield prompt per scene (style, camera move, lighting)
- Inspired by: source link
- Why it fits Magppie: 1 line from the KB
